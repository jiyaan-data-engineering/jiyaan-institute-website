Company logos for the "Trusted by" section.

Add a logo file here named after the company, lowercase, with spaces and symbols
replaced by hyphens, e.g.:
  tcs.png
  tech-mahindra.png
  hdfc-bank.png
  l-oreal.png

Use only logos you have permission to display. A company that has not agreed to be
shown should not have its logo added. Companies without a file show their name instead.
